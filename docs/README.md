# SDV 대시보드 — 단일 파일 / 모바일 배포본

이 폴더의 `index.html` 은 CSS·JS가 **하나의 파일에 모두 포함된 자가완결 버전**입니다.
(소스 원본은 `../dashboard/` 폴더에 분리되어 있습니다.)

## 안드로이드 등 모바일에서 보기

### 방법 A — GitHub Pages (URL로 접속, 추천)
1. GitHub 저장소 → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: 이 파일이 있는 브랜치, 폴더: **/docs** → **Save**
4. 잠시 후 생성되는 `https://<사용자명>.github.io/<저장소>/` 주소를
   안드로이드 크롬에서 열면 됩니다.

### 방법 B — 파일 하나만 받아서 열기
`index.html` 파일 하나만 폰에 다운로드한 뒤, 크롬에서 그 파일을 엽니다.
CSS/JS가 내장돼 있어 추가 파일 없이 단독으로 동작합니다.

> 분리형 소스(`dashboard/`)와 달리 이 버전은 파일이 하나뿐이라
> 모바일/오프라인 공유에 편리합니다. 내용 수정 시
> `dashboard/`를 고친 뒤 다시 합치는 것을 권장합니다.
